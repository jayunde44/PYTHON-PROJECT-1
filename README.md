A simple command-line based ticketing management system written in Python. This application allows users to create, view, and track the status of support or project tickets, storing data locally in a JSON format.

## 🚀 Features
* **Interactive Menu:** Easily navigate through the program options.
* **Create Tickets:** Generate new tickets with unique IDs.
* **View Tickets:** List and check the progress of current tickets.
* **Persistent Storage:** Saves all ticket data dynamically to a `tickets.json` file.

## 🛠️ Tech Stack
* **Language:** Python 3
* **Data Storage:** JSON
